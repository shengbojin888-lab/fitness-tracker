07数据存储与双向同步
—
本工作台有 8 张数据表：profile 档案、body_records 身体记录、diet_records 饮食记录、training_plans 训练计划、training_logs 训练日志、habit_logs 习惯打卡、weekly_reviews 每周复盘、diary 日记。 每条记录都带 id / updatedAt / deleted，因此可以在两台设备之间按「最后写入优先」自动合并——这就是双向同步的基础。
A · 离线可用
所有数据默认存在本机浏览器（localStorage），拔网线、关掉电脑重开都还在。手机与电脑分别打开本页，各自都完整可用。
B · 在线存储端点（可选）
填一个支持 GET 读取 / PUT 写入 JSON 的地址（任意 KV、对象存储或自建接口皆可），即可实现真正的云端存储与跨设备双向同步。
未配置端点，当前为纯本地模式。
导入快照时会按 id + updatedAt 合并，不会覆盖较新的本地记录。
